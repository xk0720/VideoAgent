# 策略卡记忆库

> 每张卡 = 一段已经拍过、量过、记下来的做法。选卡时按「商品类目 + hook 人数 +
> 段落位置」筛，再读 **实测** 与 **代价** 权衡。prompt 全部写死，pipeline 按人数
> 枚举，所见即所得 —— 没有任何一层会暗中增删步骤。

## 开场段（placement=opening）

### `beat_reel_v02` — 海报卡点开场(爆款片段驱动)
- **适用**：类目 服装/美妆/任何可做海报视觉的商品 ｜ hook 人数 [1, 2, 3] ｜ 音频 music_only ｜ BGM asset
- **人数 → 时长/步数**：1人=5s/2步，2人=5s/2步，3人=5s/2步
- **工具链**：animate_move → mix_audio
- **prompt 来源**：{'1': None, '2': None, '3': None}
- **实测**（2026-08-13）：pro/std 两轮均成功。参考图若本身是营销海报(带排版文字), 生成画面会把排版一起带进来 —— 这条链路正好要这个海报感。
- **需填内容**：无（完全写死）

## 主体段（placement=body）

### `home_talking` — 室内口播段(三动作 + 音画同步)
- **适用**：类目 服装 ｜ hook 人数 [1, 2, 3] ｜ 音频 lipsync ｜ BGM shared
- **人数 → 时长/步数**：1人=10s/3步，2人=10s/3步，3人=10s/3步
- **工具链**：kling_omni_video → isolate_voice → mix_audio
- **prompt 来源**：{'1': 'prompt_template', '2': 'prompt_template', '3': 'prompt_template'}
- **实测**（2026-08-16）：三段全成。台词 9/9 逐字准确(ASR复核), 口型同步, 身份与配色跨段稳定。 时段对齐: 台词按 3秒10-13字 配时最准(偏差<0.45s)。
  - ⚠ 代价：硬切做不到: 模型无视 hard cut, 用推拉/景别变化代替(帧差仅6-18)
  - ⚠ 代价：字幕不可控: 3段中1段自行烧了字, 且写错中文字形 → 想要准确字幕改用后期烧
  - ⚠ 代价：各段人声响度差可达11dB, 装配时必须 loudnorm 归一
- **需填内容**：无（完全写死）

### `outdoor_narration` — 户外旁白段(动作放开 + 后期字幕)
- **适用**：类目 服装 ｜ hook 人数 [1, 2, 3] ｜ 音频 voiceover ｜ BGM shared
- **人数 → 时长/步数**：1人=10s/4步，2人=10s/4步，3人=10s/4步
- **工具链**：kling_omni_video → minimax_tts → mix_audio → burn_subtitle
- **prompt 来源**：{'1': 'prompt_template', '2': 'prompt_template', '3': 'prompt_template'}
- **实测**（2026-08-16）：三段全成, 三个外景与配色匹配自然, 设计的动作逐个执行到位, 身份跨段一致。 相比 lipsync 路线的两个优势 —— 动作不受说话节奏约束; 字幕后期烧, 中文准确。
  - ⚠ 代价：TTS 与画面各自独立, 人物嘴不动; 需要真人开口感就改用 home_talking
  - ⚠ 代价：整体响度偏保守(-28~-31dB), 成片建议再做一次全片 loudnorm
- **需填内容**：无（完全写死）

## 收尾段（placement=ending）

### `sequential_reveal` — 多人相继出镜(收尾)
- **适用**：类目 服装/任何多SKU或多配色商品 ｜ hook 人数 [2, 3] ｜ 音频 music_only ｜ BGM generated
- **人数 → 时长/步数**：2人=4s/5步，3人=6s/5步
- **工具链**：kling_omni_video → sonilo_text_to_music → punch_up → mix_audio → burn_text
- **prompt 来源**：{'2': 'prompt_2p', '3': 'prompt_3p'}
- **实测**（2026-08-16）：3 人版实测: 时序精准(1s 一人 / 2.5s 两人 / 4.5s 三人), 背景完美复刻, 抠图白描边到位, 三人未串脸(记忆卡标注的高风险项被规避)。
  - ⚠ 代价：最后一击需 ~0.55s 衰减: 音乐要多生成 2s, 强化后裁到 段长+0.5s, 段落画面同步延长(末帧克隆=定格)
  - ⚠ 代价：否则拼接后该击被后段音频覆盖, 成片里等于消失(实测强度 0.00)
  - ⛔ 跳过条件：`person_count < 2`
- **需填内容**：无（完全写死）

## 选卡口径（给模型的判断依据）

| 商品/素材特征 | 选项                  | 理由                 |
|---|---------------------|--------------------|
| 想要真人开口的信任感 | `home_talking`      | 台词逐字准确、口型同步（实测 9/9） |
| 想要动作花哨、字幕必须准 | `outdoor_narration` | 动作不受说话节奏约束；字幕后期烧，中文准确 |
| 手上有对味的爆款片段 | `beat_reel_v02`     | 动作是真拍的，比生成的自然      |
| hook ≥2 张且要强收尾 | `sequential_reveal` | 多人相继出镜，实测未串脸       |
| hook 只有 1 张 | 收尾段省略               | 该卡 person_count 不含 1 |

## 跨卡铁律（选哪张都适用）

- **硬切做不到**：animate 会抹平驱动片段的硬切，seedance 无视 `hard cut` 改用推拉。要卡点硬切 → 后期剪。
- **整数铁律**：生成时长与时间戳只能整数秒，窗口最小 1s。
- **中文语速**：TTS 约 5 字/秒；口播 3 秒句配 10-13 字，旁白 10 秒配 26-30 字。
- **收尾一击要留衰减**：音乐多生成 2s、裁到 段长+0.5s，画面同步延长，否则最后那记重击在成片里消失。
- **安全动作**：走位/甩袖/摇肩/撩发/回眸/比心均一次成功；禁 `360` `spin` `rotate quickly`。
