# 从"理解"到"经验"：两层结构与它们的接口

## 为什么要分两层

Omni 拆出来的是**这条视频为什么爆**（一次性的、绑定原商品）；
拍法卡记录的是**我们要怎么复刻它**（可复用的、待套新商品）。

两者不能合并：前者是观察，后者是做法。一条爆款可能拆出三段，其中只有两段值得沉淀成拍法；
一张拍法卡也可能综合了两条爆款的同类做法。

```
爆款视频 ──Omni拆解──→ ① 拆解卡（一条视频一张）
                              │  只保留 is_skeleton 的段落
                              ↓
                        ② 拍法卡（一种做法一张）──→ 生成时被选用
```

## ① 拆解卡：记录"为什么爆"

字段见 `decompose_viral.md` 的输出结构。三处设计要点：

**骨架与修饰分离**（`attribution.skeleton` / `decoration`，段落级 `is_skeleton`）
只有骨架进入第二层。这一步把"这条视频的全部特征"过滤成"必须保留的少数几条"。

**形与神分开记录**（`form` / `spirit`）
形用于复刻拍摄手法，神用于判断能否迁移到新商品。`spirit.transferable` 明确回答"换一种形
还能不能承载同样的神"——这决定了这段该做完整复刻还是结构复刻。

**前提条件成对出现**（`precondition` / `anti_precondition`）
不写"什么商品能用"就没法防住红线三。反例必须一并写出：什么商品硬套会出现"前 3 秒能打、
看完不想买"。

## ② 拍法卡：记录"怎么复刻"

在原有字段（适用条件、写死的提示词、生产步骤、实测结论）之外，从拆解卡继承三组新字段：

```yaml
# ── 从拆解卡继承：这个做法为什么有效 ──
mechanism:
  layer: attraction              # 承担吸引力/说服力/转化力的哪一层
  why_stop: rhythm               # 神：用户为什么在这里停下来
  spirit: 连续硬切+卡点制造节奏冲击，观众来不及划走
  form: 固定机位、每 0.8s 一个硬切、切点全部压在鼓点上
  transferable: 节奏是效果本身，换成慢节奏就不成立 → 只能完整复刻

# ── 从拆解卡继承：什么商品能套用 ──
applicable_when:
  - 商品有视觉可展示的多个款式或配色
  - 商品调性适合快节奏、年轻化的表达
not_applicable_when:
  - 商品需要讲原理或功效对比（快切放不下信息量）
  - 单一款式且外观差异小（换姿势看不出变化，节奏落空）
  risk: 硬套会出现停留数据好、但看完不知道在卖什么

# ── 沿用已有：实测与代价 ──
measured: {...}
caveats: [...]
```

## 接口：选拍法时如何用上这些字段

新商品进来时，先确定它的**说服路径**（靠功效对比、场景还原、还是价格优势），再按下列顺序过滤：

1. **硬过滤**——`not_applicable_when` 命中即排除。这是红线："新商品在这个框架里讲不通的
   部分，不复刻"，宁可少一段也不硬套。
2. **机制匹配**——比较新商品的说服路径与拍法卡的 `mechanism.spirit`。路径不同的不选，
   即使品类相近。
3. **实测权衡**——同样匹配时，看 `measured` 与 `caveats` 挑代价可接受的。

这条过滤链把需求里的三条原则落到了可执行的判断上：先归因（第 2 步比的是神不是形）、
保神优先（`transferable` 决定粒度）、讲不通就不复刻（第 1 步硬过滤）。

## 粒度与场景的对应

拆解卡的 `reuse.grain` 直接决定这段进入哪种复刻：

| grain | 含义 | 对应场景 | 落地形态 |
|---|---|---|---|
| `full` | 效果绑定在具体动作/节奏/音画上 | 完整复刻 | 借原片段作驱动，只换主体 |
| `structure` | 信息顺序与句式可迁移，内容须重写 | 结构复刻 | 保留拍摄结构，台词按新商品重写 |
| `none` | 依赖原商品独有属性或无法复现的手段 | 不复刻 | 跳过，或换其他拍法补位 |

复刻 Hook 属于**局部强借鉴**：头尾按 `full` 拿走，中段按 `structure` 重做。
完整复刻属于**整体受控改写**：全片按 `full` 保留骨架，只替换主体或翻译文案。
