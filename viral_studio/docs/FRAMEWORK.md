# 爆款视频复刻智能体框架技术文档

## 1. 概述

本框架用于短视频广告的自动化复刻生产：将已验证的爆款视频拆解为可复用的拍摄方法（技能卡），由智能体根据商品信息选择拍法、生成文案并完成视频生产。输入为商品说明与人物、商品参考图，输出为完整成片。

成片采用三段式结构：钩子段（开场吸引）、展示段（卖点呈现）、转化段（引导下单）。每个段位对应若干技能卡；一张技能卡完整封装一种拍法，包含适用条件、生成管线、提示词模板、文案槽位与经过验证的参数。

框架由四个 Agent 构成：

- 理解 Agent：拆解爆款视频并蒸馏为技能卡（已完成设计，待接入）；
- 编剧 Agent：选择技能卡，生成台词、旁白与动作描述；
- 导演 Agent：将分镜脚本编译为可执行调用计划，负责计划校验与执行失败决策；
- 执行 Agent：调度远程生成与本地合成，产出成片。

LLM 仅用于三个环节：技能卡选择、文案生成、超出既定规则的失败决策；其余环节均为确定性代码实现。该设计基于成本约束：视频生成按时长计费且不可回滚，所有可静态判定的错误均应在提交前拦截。

## 2. 处理流程

```
商品 brief + 人物图/商品图
    ↓
编剧 Agent：选卡（LLM）→ 写稿（LLM）→ 分镜脚本
    ↓
导演 Agent：确定性编译 → 逐步调用计划 + 计划校验
    ↓
预检：14 类静态检查，存在错误则不进入执行
    ↓
执行 Agent：远程生成（视频/语音/音乐）+ 本地合成（拼装/字幕/混音）
    ↓
成片 + 执行台账
```

主要设计原则：

1. **策略可指定。** brief 中的 `skill_overrides` 字段可指定各段位使用的技能卡；未指定的段位由 LLM 在候选中选择。用于满足运营侧指定拍法的需求。
2. **管线显式化。** 调用计划的每一步均在技能卡中显式声明，框架不隐式插入处理环节，保证计划可审查、可复现。
3. **静态检查前置。** 生成接口的参数约束（时长取值范围、图片引用编号上限、口播语速与镜头时长的匹配等）均可在提交前判定；预检不通过则不进入付费执行。
4. **产物签名与断点续跑。** 每步产物按（段落，步骤）命名，签名由参数与上游签名递归计算；重跑时仅执行签名变化的步骤，已生成素材不重复计费。签名与产物内容绑定，防止参数变更后复用过期产物。
5. **失败降级。** 单步失败不废弃整段：后期步骤（配乐、字幕）失败时回退至该段最后一个可用画面；单镜头生成被拒时以同人物的成功镜头按原时长补位，保持切点时间轴不变。

## 3. 模块说明

**技能卡库（SkillStore）**。技能卡以 YAML 定义，按商品类目、人物数量、段位、商品绑定四个维度筛选候选。商品绑定用于内嵌专属素材（驱动片段、景别参考图）的卡片，防止跨商品误用。

**编剧 Agent（StoryboardPlanner）**。两次 LLM 调用：第一次完成主体段选型并输出选择理由；第二次按选定卡片的槽位生成文案，包括台词、旁白、标题与英文动作描述。采用两次调用而非单次嵌套输出，原因是嵌套 JSON 输出的稳定性不足。文案生成配有四类校验：字数按语言分别计数（中文按字、英文按词）；高风险动作词过滤（旋转、跳跃等生成质量不稳定的动作）；道具一致性检查（不允许出现参考图之外的服装或道具）；句式约束（`must_match` 正则，如双人场景要求以具体人物指代开头）。校验不通过的条目连同具体问题反馈至下一轮重写，直至收敛。

**导演 Agent（ActAgent）**。正常路径为确定性编译：将占位符（`$hook_N` 人物图、`$item_N` 商品图、`$skill.assets.*` 卡内资产、`{slot}` 文案、`@id` 运行期产物引用）替换为实际值，输出逐步调用计划；配套校验器检查工具注册、必填参数、引用可达性。LLM 仅用于异常路径：失败类型可枚举（人物检测失败、内容审核、网络异常、超时），规则内的失败按既定策略处理，规则外的由 LLM 判定重试、调参、降级或跳过。

**预检（pretest）**。14 类静态检查，覆盖提示词格式、时长取值域、口播语速与镜头窗匹配、素材文件存在性、时间轴连续性、槽位对齐等，作为付费执行前的强制关卡。

**执行 Agent（Executor）**。按段执行调用计划。远程后端（可灵、animate、TTS、音乐生成）按需加载，计划未使用的路线不要求配置密钥。失败按类型处理：前置检测类拒绝（NoHuman/FullFace）为确定性结果，不重试；网络类错误重试一次。执行过程逐步记录耗时、任务号与错误信息。

**本地工具集**。拼装、混音、字幕、卡点强化等约十个工具，关键参数均经实测确定：人声分离固定使用 CPU 推理；中文字幕由本地渲染后叠加，不依赖生成模型输出文字；人声混音前统一响度归一。

## 4. 技能卡示例

一张技能卡由四部分构成：筛选条件（`applies_to`）、产出声明（`produces`/`audio`）、生成管线（`pipelines`，按人数分版本）、文案合同（`text_params`，编剧 Agent 写稿的依据）。以下以双人对话卡为例，注释说明各字段的作用与取值依据。

```yaml
skill_id: duo_interaction
kind: template                # 模板型: 结构固定, 问答内容与动作由编剧 Agent 填写
name: 双人同框对话种草(问答体)

applies_to:                   # 选卡阶段的筛选条件
  categories: [服装]
  person_count: [2]           # 对话体仅在恰好两人时成立: 一人无对话, 三人分工混乱
  placement: body             # 展示段

produces:
  durations: {"2": 20}        # 两条 10 秒同框片段
  audio_mode: voiceover       # 对话由 TTS 双音色合成, 与画面分离。不启用生成模型
                              # 的原生口型: 双人同框时模型难以区分当前说话者,
                              # 口型对位不稳定

audio:
  bgm_source: generated       # 背景乐现场生成, 混音时压低音量垫底

prompt_source:                # 第 N 条片段使用第 N 段提示词模板
  "1": prompt_clip1
  "2": prompt_clip2

pipelines:
  "2":                        # 两人版管线, 共 15 步
    # 两条同框画面: 两张人物图同时挂参考; 提示词内固化同尺寸、同景深、
    # 不串脸的约束语句(沿用多人同框卡的已验证版本)
    - {id: vid1, tool: kling_omni_video,
       params: {prompt: $prompt_1, audio: false, duration: 10,
                refer: [$hook_1, $hook_2]}}
    - {id: vid2, tool: kling_omni_video,   # 同构, 取 prompt_clip2
       params: {prompt: $prompt_2, audio: false, duration: 10,
                refer: [$hook_1, $hook_2]}}
    - {id: joined, tool: concat_av, local: true,
       params: {videos: ["@vid1", "@vid2"]}}   # "@id" 引用前序步骤的产物
    # 四对问答共 8 条语音: 问句与答句使用不同音色区分说话者
    - {id: q1v, tool: minimax_tts, params: {text: "{q1}", voice_id: Lively_Girl}}
    - {id: a1v, tool: minimax_tts, params: {text: "{a1}", voice_id: Sweet_Girl_2}}
    # ...... q2v/a2v/q3v/a3v/q4v/a4v 同构, 共 8 步 ......
    # 语音按 2.5 秒窗落位到 20 秒时间轴, 空隙补静音;
    # 落位表与字幕窗完全一致, 保证声音、字幕、画面三方对齐
    - {id: vo, tool: concat_audio, local: true,
       params: {audios: ["@q1v", "@a1v", "@q2v", "@a2v", "@q3v", "@a3v", "@q4v", "@a4v"],
                slots: [{t0: 0}, {t0: 2.5}, {t0: 5}, {t0: 7.5},
                        {t0: 10}, {t0: 12.5}, {t0: 15}, {t0: 17.5}],
                duration: 20}}
    - {id: music, tool: sonilo_text_to_music,
       params: {prompt: $skill.music_prompt, duration: 22}}  # 多生成 2s 作裁剪余量
    - {id: mixed, tool: mix_audio, local: true,
       params: {video: "@joined", voice: "@vo", bgm: "@music",
                duration: 20, voice_loudnorm: -18, bgm_volume: 0.2}}
                              # 人声先归一至 -18LUFS 再混; BGM 压至 0.2 不抢人声
    - {id: out, tool: burn_subtitle, local: true,   # 字幕本地渲染烧录, 中文零差错
       params: {video: "@mixed",
                segments: [{t0: 0, t1: 2.5, text: "{q1}"},
                           {t0: 2.5, t1: 5, text: "{a1}"}]}}  # ... 共 8 窗

text_params:                  # 文案合同: 每槽声明语言、长度域与写作语境
  q1: {lang: zh, chars: [8, 12],       # 2.5s 窗按 5 字/秒 → 上限 12 字
       desc: "第1问(0-2.5s, 第一人问): 替观众开口的疑问, 如版型/显胖/场合"}
  a1: {lang: zh, chars: [12, 16], desc: "第1答: 用一个卖点正面回应第1问"}
  # ... 四对问答逐对递进: 版型 → 细节材质 → 颜色选择 → 价值收束 ...
  act_1: {lang: en, chars: [12, 28],   # 英文动作槽按词计数
    must_match: 'the woman (in [a-z]+|on the (left|right))',
    must_match_hint: '双人动作必须指名道姓, 不允许只写 she',
    desc: "前10s两人互动编排: 仅用指/看/比/递/点头等低风险动作;
      不得出现参考图之外的服装或道具; 禁旋转跳跃"}
```

其余卡片按同一规格组织：`beat_pose_reel`（资产驱动型，内嵌爆款驱动片段与帧号时长表）、`home_talking`（音画同出口播型）、`outdoor_narration`（声画分离旁白型）、`sequential_reveal`（多人收尾型），在案例部分结合成片说明。

## 5. Demo 结果

两条样片位于 `yike-demo/`，商品均为水彩小马印花卫衣（三色），人物与商品图为同一组输入。

**案例一（case1.mp4，41.1 秒）**——三段式全流程：

| 时间 | 段位 | 技能卡 | 生成方式 |
|---|---|---|---|
| 0–6.1s | 钩子 | sequential_reveal | 三人同框依次入镜，单次生成；配卡点音乐并做重音强化 |
| 6.1–11.1s | 动作引导 | beat_reel | 真实爆款片段驱动人物动作迁移，沿用素材自带 BGM |
| 11.1–41.1s | 展示 | home_talking ×3 | 三个配色各 10 秒室内口播，音画同出；人声分离后垫生成 BGM，字幕本地烧录 |

本片同时验证段落重组：收尾卡前置作钩子（运营指定）。九句口播经语音识别逐句核对，与脚本完全一致。

**案例二（case2.mp4，38.4 秒）**——爆款节奏复刻与存量改造：

| 时间 | 段位 | 技能卡 | 生成方式 |
|---|---|---|---|
| 0–8.6s | 钩子 | beat_pose_reel 系 | 13 秒爆款按帧号拆为 9 镜逐镜动作迁移；每镜按原片景别匹配三档参考图（机制见下）；沿用原片音轨，切点时序不变 |
| 8.6–38.4s | 展示 | outdoor_narration ×3 | 樱花园、植物园、海滨三场景各 10 秒；声画分离，TTS 旁白与本地字幕 |

**景别参考图机制**。景别指画面中人物的取景范围，本卡划分为近景（胸像）、中景（腰部以上）、全身三档。设置三档参考图的原因是一条实测结论：动作迁移模型（wan2.2-animate）输出画面的取景由参考图决定，与驱动视频的取景无关——参考图为全身像时，即使驱动片段是近景特写，生成结果仍为全身构图。因此复刻原片的景别变化，必须为每个镜头配置与其原始景别一致的参考图：拆解阶段以人脸高度占画面高度的比例度量各镜头景别并归入三档，生成阶段按档位取图。

三张参考图的制备（预处理，非管线环节）：以人物图为参考生成一条 5 秒运镜视频——人物保持静止，镜头由全身机位匀速推进至胸像——再在对应三档的时间窗内各抽取清晰度最高的一帧。三档图像取自同一条连续镜头，人物、服装、背景与光线严格一致，避免三次独立生成造成的形象偏差。

开场 9 镜合成后切点位置帧级命中（检出 7/8，误差不超过 0.017 秒）；该开场为对既有正片的局部替换，演示框架对存量视频的改造能力。
