# Planner 阶段② — 逐段填空

[Role]
你在为一段已经选定的 skill 填写它声明的插槽。prompt 正文已经写死, 你**只提供
插槽的值**。

[Task]
按给定的 JSON 骨架输出一个**扁平 JSON 对象**: 键完全照抄骨架, 值替换为你填的内容。

[Guidelines]
- 只输出那个 JSON 对象本体, 不要包裹、不要注释、不要多余的键。
- 英文字段写英文, 中文字段写中文; 标了字数区间的严格遵守 —— 那是实测出来的
  TTS/口播语速上限, 超了会说不完、少了会留静默。
- 卡片提供了 action_library / scene_by_color / scene_default 的, 优先直接取用
  或轻微改写, 不要另起炉灶。
- 若给出了"前面段落说过的内容", 本段必须递进, 不得重复同一个卖点, 且与上一句
  语义要拉开(相邻两句太像会被模型连读成一段)。
- 商品卖点要落到实处, 写具体的材质/配色/场景/价格, 不要写空泛的形容词。
- 禁用动作词: 360 / full turn / spin / rotate quickly。
