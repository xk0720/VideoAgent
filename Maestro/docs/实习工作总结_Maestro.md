# 面向多镜头叙事视频生成的条件构造方法与策略优化

**实习工作总结**

---

## 摘要

多镜头叙事视频生成的核心困难,不在于单镜头的画质,而在于跨镜头的一致性:同一角色在不同镜头中长相漂移,同一场景换一个机位便成为另一个空间,镜与镜之间的硬切割裂了空间与时序的连续性。已有工作大多沿"增强模型"的路径求解——引入身份适配器、显式三维重建或相机可控模块,这类方案依赖对模型权重的干预,在以闭源 API 为视频后端的工程条件下难以落地。

本文提出一个不同的视角:**跨镜一致性问题的本质是条件构造问题**。每一镜生成什么,取决于我们向生成模型喂入了什么条件;因此一致性可以在不改动生成模型的前提下,通过"构造更对的条件"来获得。围绕这一主张,本文给出一条完整的解法链:条件的**素材**如何无中生有、条件的**记忆**如何跨镜跨片留存、条件的**决策**如何学会做对。

对应地,本文的三项工作是:(1) 提出**隐式几何物化**方法,利用视频扩散模型在预训练中已隐式习得的三维空间与镜头运动先验,通过定向摇镜自举出同一场景的多朝向视图,并通过双镜切换视频推理出切点之后的首帧,从而在不引入任何显式三维模块的前提下获得跨镜可复用的视觉锚点;(2) 设计**分层记忆系统**,将片内台账、在线增长的空间记忆与跨片的经验/技能记忆分层组织,支撑长片生成中的状态保持与经验复用;(3) 将逐镜的条件决策形式化为序贯决策问题,采用**主干择优的组相对策略优化(Trunk-GRPO)**,以文本判官与原生视频判官构成的结果型奖励进行训练,并针对视频域反馈昂贵、稀疏、高方差的特点,设计逐镜成组、镜间换脑的半在线训练架构。

〔待补:关键定量结果一句,例如一致性维度相对基线的相对提升〕

**关键词**:多镜头视频生成;跨镜一致性;条件构造;隐式几何物化;分层记忆;组相对策略优化

## 1 引言

### 1.1 研究背景与问题

视频生成模型在单镜头质量上已经取得显著进展,但**把若干个高质量镜头拼接起来,并不等于得到一部片子**。当生成任务从"一个镜头"扩展到"一段叙事"时,新的困难来自镜与镜之间,而非镜头之内。

在实际生成中,这些困难集中表现为四个方面:

**C1 空间不一致。** 每一次生成调用都是独立采样,模型不持有跨调用的持久三维场景表示。同一个房间,换一个机位就变成了另一个房间——墙的颜色、门的位置、家具的布局都可能改变。

**C2 时序断裂。** 镜与镜的交界处缺乏可用的过渡先验。若直接硬切,人物姿态与空间关系在切点处发生跳变;而这一跳变恰恰是观众最敏感的地方。

**C3 状态遗忘。** 一部长片所涉及的信息量超出单次上下文所能承载的范围;同时,一次生成中获得的经验无法在下一次生成中复用,系统不会随使用而变好。

**C4 决策组合爆炸。** 每一镜"该用哪些条件、提示词怎么写"构成一个巨大的组合空间:条件策略是离散的,参考素材的组合是组合式的,提示词本身则是连续的自然语言空间。手写规则难以覆盖长尾,而监督学习又缺乏标签。

已有工作对 C1、C2 的主流应对是**增强模型本身**:训练身份保持适配器、外挂三维重建以提供显式几何、或引入相机可控生成。这些方案的共同前提是可以干预模型权重或内部结构。在本项目的工程约束下——视频后端为闭源商用 API——这一前提不成立。

### 1.2 核心主张与技术路线

本文的主张是:

> **跨镜一致性问题可以重构为条件构造问题。** 生成结果的一致性,取决于喂给生成模型的条件是否正确;因此,与其增强模型,不如构造条件。

这一重构把一个"模型能力问题"转化为一个"系统设计与决策问题",并自然地分解为三个递进的子问题,构成本文的技术路线:

| 环节 | 待答问题 | 本文方法 |
|---|---|---|
| **素材** | 跨镜一致所需的视觉锚点从何而来? | 隐式几何物化:多视图空间锚定 + 镜间交界派生(第 2 章) |
| **记忆** | 锚点与历史决策如何跨镜、跨片留存与取用? | 分层记忆系统(第 3 章) |
| **决策** | 每一镜究竟该用哪些锚点、如何写提示词? | Trunk-GRPO 策略优化(第 4 章) |

其中前两环是**训练无关的系统设计**,第三环是全系统中**唯一引入学习**的部分。这一取舍本身是一个有意的设计决定:在一个由二十余个智能体协作的管线中,只有少数决策点同时具备"决策空间大"与"后果可客观测量"两个性质,值得付出训练代价。

### 1.3 主要工作与贡献

1. 提出**隐式几何物化**方法,论证并实现了"用视频生成模型自身的生成能力,把其内部隐式的三维几何先验物化为显式视觉锚点,再作为条件回灌"这一路径,避免了外挂三维重建模块。
2. 提出**在线增长的空间记忆**机制:每镜生成完成后,其尾帧经去人物处理与语义标注后回流为该场景的新视图,使空间表示随片长自动变得完备。
3. 将逐镜条件决策形式化为序贯决策问题,设计了与任务语义对齐的复合奖励(格式 / 文本判官 / 原生视频判官),并给出适配视频域反馈特性的**半在线 Trunk-GRPO 训练架构**。
4. 给出一份**负面结果的根因分析**:以 vLLM 服务 LoRA 策略的方案在张量并行条件下整体失效,据此重构为本地推理架构。

## 2 隐式几何物化:多视图空间锚定与镜间交界派生

### 2.1 核心洞察

视频扩散模型在大规模预训练中已经隐式习得了三维空间与镜头运动的先验——它能够生成连贯的摇镜,也能够生成保持空间关系的镜头切换。既然这份几何知识已经存在于模型内部,那么:

> **我们不需要外挂显式的三维重建模块,只需要用模型自己的生成能力,把这份隐式几何"拍出来、定格成图像资产",再作为条件回灌给它自己。**

本文将这一路径称为**隐式几何物化(Implicit Geometry Materialization)**。它有两个具体实例:用摇镜物化"空间",用双镜切换物化"切换后的相机位姿"。二者共享同一份空间表示,并非彼此独立的技巧。

### 2.2 多视图空间锚定

给定一张空场的背景板,系统向视频模型发出定向摇镜指令,生成一对约 180° 的摇镜视频,再从中抽帧,即得到同一空间在多个朝向下的视图。每个视图由视觉语言模型标注一句**固定元素清单**(墙体、门窗、家具及其相对位置),该清单是后续视图选取与几何核验的唯一判据。

这一设计中有三处约束来自实测,值得记录:

- **背景板必须空场。** 若板上含有人物,该人物会污染后续所有以此视图为参考的生成结果,造成身份串扰。
- **图注刻意排除天色、光照与时辰。** 早期版本未作此排除,导致下游的几何核验将"红霞"与"橙蓝晚霞"判定为空间矛盾,连续三次拒绝了几何上完全正确的结果。**几何一致性与光照一致性必须解耦**,否则核验器会在错误的维度上行使否决权。
- **近重复视图需去重。** 以像素平均绝对差为判据剔除高度相似的视图,防止视图池被冗余样本撑爆而稀释有效朝向。

**在线增长机制。** 空间表示并非一次性构建后即固定。每一镜生成完成后,系统取其尾帧,经去人物处理与语义标注后,若不与已有视图重复,则**追加为该场景的新视图**。这构成一个自监督的记忆增长回路:片子拍得越长,该场景的空间表示越完备,后续镜头可选的锚点越多。

### 2.3 镜间交界派生

对相邻两镜,系统首先由一个判官智能体做三路分诊:依据上镜结尾与本镜开场各自的在场人物集合与场景标识,判定交界模式为**派生 / 硬切 / 延续**;该判定同时配有基于集合比对的确定性兜底。

在需要派生时,执行以下链路:

1. **上镜实况观测。** 由视觉语言模型读取上镜尾段,输出机位角度与各人物的实际动作。此处有一个重要的概念区分:**剧本所写的"结束状态"是意图,而尾段观测得到的是事实**;条件必须建立在事实之上,否则计划与执行的偏差会沿链路累积。
2. **双镜脚本生成。** 一个专职智能体依据上镜实况、本镜开场意图与选定的空间视图,写出一段"两镜……切至……"的双镜脚本。其输出须通过四级校验(非空、引用符号属于合法槽位、不含裸露人名、语言一致),失败则回退至确定性模板。
3. **切后首帧抽取。** 生成该双镜视频,定位切点,抽出**切点之后的第一帧**。这一步的实质是:我们并不显式计算"切换之后相机在哪、人物落在画面何处",而是**把这次空间推理外包给视频模型本身**,再把推理结果取回。
4. **几何核验。** 由核验环节比对该帧与选定视图的固定元素排布,天色光照一律豁免。核验采取**失败即放行**的策略:一个不完美的核验器若拥有否决权,其误拒代价大于其纠错收益;两次被拒才降级为硬切。

通过核验的帧作为"钉帧参考图"进入本镜的条件集合。

### 2.4 两者的耦合

派生时,选定的空间视图与其图注会一并作为参考喂入,使镜头切换发生在**已知的空间**之中而非凭空推演;而派生所得的尾帧又会回流补充该空间的视图池。二者因此构成一个闭环:空间表示支撑交界推理,交界结果反过来充实空间表示。

## 3 记忆系统

为了让长片生成既"记得住全局"、又"每次只看必要的信息",系统将记忆组织为两层:

| 层 | 内容 | 载体与生命周期 |
|---|---|---|
| **工作记忆** | 当前这一次决策所需的最小上下文:本镜分镜条目、上一镜结尾的实际状态、可用参考图清单、条件方式菜单 | 每次调用时现场拼装,用后即弃,不落盘 |
| **情景记忆** | 全片的唯一事实来源:剧本分镜、人物肖像、背景板、空间视图,以及每一镜的决策、评审与生成结果 | 台账文件,每次状态变更立即回写,贯穿一部片 |

两层的关系是**单一事实来源、按需投影**:情景记忆完整记录一切,工作记忆是它在每次决策时刻的一个切片。由此,单次调用的上下文规模不随片长增长,而全片任何历史又都可追溯;台账逐次落盘,也使任一环节中断后都能从断点恢复续跑,已完成的镜头无需重新生成。

以下两例说明其作用方式:

**例一(工作记忆)。** 生成第 t 镜时,条件决策智能体的输入仅包含本镜的分镜条目、上一镜结尾的实际画面状态、本镜可用的参考图清单与条件方式菜单——即便全片已完成数十镜,单次决策的输入规模不变,决策也不会被无关的历史信息干扰。

**例二(情景记忆)。** 第 3 镜在便利店场景完成后,其尾帧经去除人物并查重后,作为该场景的一个新视角写入台账;第 6 镜重回便利店、以不同机位拍摄时,系统从台账中取出该视角作为空间参考,保证两镜的空间布局一致。

此外,系统还支持跨片层面的经验归档与人物肖像复用,不属本文重点,不展开。

## 4 Trunk-GRPO:面向条件决策的组相对策略优化

### 4.1 目标与动机

**采用强化学习,增强逐镜的条件决策能力。** 条件决策指每一镜生成前选定生成方式(文本 / 首帧 / 首末帧 / 参考图 / 续拍上镜等)、指定接入的视觉锚点(肖像、空间视图、派生首帧)并写出最终提示词,直接决定成片质量与跨镜一致性。该环节手写规则覆盖不了长尾,监督微调又无标签可用——决策的对错只有在视频生成之后才能判断——故让策略以强化学习直接从生成结果中改进。

**为了在昂贵、稀疏的奖励下稳定训练,并使训练分布贴近部署行为,采用主干择优的组相对策略优化(Trunk-GRPO)。** 同一状态下采样 K 个候选成组,以组内均值为基线互相比较,免去难以训练的价值网络,并消除镜头难易差异带来的偏置;组内得分最高的候选被用于推进剧情,使后续镜头始终建立在最优分支上,与部署时的贪心生成保持一致;策略仅在镜与镜之间更新,以半在线方式适配单镜分钟级的生成耗时。

### 4.2 方法

**〔图 1 占位:Trunk-GRPO 训练系统流程图——N 条采样流(各占一卡,本地推理)→ 视频生成与判官打分 → 组队列 → 训练器(单/双卡)→ LoRA 定期广播回流各采样流。图由作者绘制填入。〕**

#### 4.2.1 概述

训练的基本单元是**组**:在同一镜的同一状态下,策略以温度采样产生 K=4 个候选决策(一段 JSON,含条件策略与视频提示词),每个候选各自完成真实的视频生成并由判官打分,构成一次同状态下的公平对比。区别于标准 GRPO 之处在于**主干择优(trunk selection)**:组内得分最高的候选被用于推进剧情,后续镜头在这一最优分支的状态上继续采样。这会使训练状态分布偏向高奖励区域,但部署时系统本就采用贪心解码,偏置方向与部署分布一致,属有意设计而非疏漏。

策略以 LoRA(秩 64,作用于注意力四投影)形式训练,训练目标为:

$$
\mathcal{L}(\theta)
=-\frac{1}{\sum_{i}\lvert y^{(i)}\rvert}
\sum_{i=1}^{K}\sum_{l=1}^{\lvert y^{(i)}\rvert}
\min\Bigl(
\rho^{(i)}_{l}A^{(i)},\;
\operatorname{clip}\bigl(\rho^{(i)}_{l},\,1-\varepsilon_{\text{low}},\,1+\varepsilon_{\text{high}}\bigr)A^{(i)}
\Bigr)
+\beta\,\widehat{D}_{\mathrm{KL}}\bigl(\pi_{\theta}\,\Vert\,\pi_{\text{ref}}\bigr),
\qquad
A^{(i)}=\frac{r^{(i)}-\bar r}{\sigma+\epsilon}
$$

其中 $A^{(i)}$ 为组相对优势($\bar r,\sigma$ 为组内奖励的均值与标准差),$\rho^{(i)}_l$ 为 token 级重要性比值(相对采样时刻记录的行为策略)。三个部件各治一件事:组相对优势解决"跟谁比"——以组均值为基线,免去价值网络;非对称裁剪(取 0.2/0.3,上界更宽)解决"步子迈多大"——为正优势 token 保留更大上升空间以缓解熵坍缩;KL 项(k3 估计量,系数 $10^{-3}$)解决"漂多远"——将策略拉回基座 $\pi_{\text{ref}}$,防止长程漂移。由于策略是 LoRA,关闭适配器即精确等于基座,参考策略零成本获得。组内奖励打平时优势恒零,该组直接跳过,不做无意义的优化步。

#### 4.2.2 奖励设计

一个候选是一段文本(策略选择 + 提示词),真实后果却是一段视频,因此评分分三级、由浅入深:

**格式检查——能不能执行。** 与生产管线相同的机械校验(JSON 可解析、策略在菜单内、引用的素材真实存在等),不用模型、瞬时完成。它只做门槛不做激励:实测中其占比一旦过高,策略会转而输出格式完美、内容空洞的提示词来换取高分。

**文本判官——写得对不对。** 一个冻结的文本大模型,拿着与策略决策时完全相同的材料(分镜、人物设定、交界信息、素材清单)审这条提示词,按四个维度打分:是否忠于分镜、画面是否具体可拍、与上一镜是否衔接、人物引用是否规范。每维依据评分细则给 1–5 的整数分,并须引用原文证据说明扣分点(例如指出提示词遗漏了分镜中的某个动作),防止空泛打分;四维取平均并归一到 0–1 作为该候选的文本分。其中"衔接"仅在同人同景时参评,不适用时记空、不计入平均——硬切不欠连续性,强行打分等于惩罚正确决策。

**视频判官——拍得好不好。** 一个多模态大模型直接观看 K 段成片。同组候选出自同一状态,天然可比,故不采用多模态模型标定不可靠的绝对打分,而是将 K 段视频放在一起排名(表演 / 物理 / 运镜),展示顺序随机打乱以消除位置偏好;唯"一致性"(人物是否忠于官方肖像、布局是否忠于场景视图)按客观清单逐项判定——当组内候选整体低质时,排名仍会选出一个"相对最好",只有绝对判定能守住质量底线。

三级得分按"格式为门槛、视频结果占大头"的权重合成最终奖励;某级判官失效则剔除该项、其余权重归一,绝不以 0 分冒充评审结果——伪造的 0 会污染组内比较。

#### 4.2.3 训练技巧

为了让分钟级的视频生成不阻塞秒级的梯度更新、并使采样吞吐可随卡数线性扩展,我们采用"训练与推理分离"的架构:训练进程只负责更新 LoRA 权重;多条推理进程并行运行完整的生成管线、负责采样(推理端使用本地权重或推理服务均可);两者通过文件队列交换样本,训练器每隔若干步向推理端广播最新权重,且推理端只在镜与镜之间切换版本,保证同一组的 K 个候选来自同一策略。

为了让梯度准确作用在真实的采样分布上,训练端直接复用采样时记录的 token 序列与温度;为了控制显存,只计算回复位置的 logits 并开启梯度检查点,14B 模型单卡训练的显存峰值从约 96 GB 降至约 37 GB,并支持双卡拆分训练。

### 4.4 小结与收获

- 在反馈昂贵、稀疏、高方差的生成任务上,GRPO 的组内相对比较是比训练价值网络更稳健的基线选择;主干择优进一步使训练轨迹与贪心部署的状态分布对齐。
- 奖励中的形式合规项只能做门槛,不能做激励,否则必被策略钻空子。
- 训练与采样的分布一致性(同一串 token、同一温度、不截断采样),以及训练与生产环境的一致性(同构锁),都必须机器可验——本阶段代价最大的两次故障(vLLM 服务失效、logits 截断参数被静默吞掉)均源于"不报错的错误",人工纪律防不住,只有自动化检验防得住。

## 5 工作总结与展望

### 5.1 工作总结

本文围绕"多镜头叙事视频生成中的跨镜一致性"这一问题,提出将其重构为**条件构造问题**,并沿"素材—记忆—决策"三环给出了完整解法:以隐式几何物化自举出跨镜可复用的视觉锚点,以分层记忆支撑长片的状态保持与经验累积,以 Trunk-GRPO 训练逐镜条件决策。全系统在不干预视频生成模型权重的前提下运行,适配闭源商用后端。

### 5.2 局限

- 隐式几何物化依赖视频模型自身的几何先验,当该先验在特定场景下失效时,自举出的视图本身即不可靠,而当前的核验环节采用失败即放行策略,难以完全拦截此类情形。
- 训练目前仅覆盖单一决策点,其余智能体保持冻结;多智能体联合训练下的信用分配尚未处理。
- 判官本身是被优化的对象所面对的环境,存在被策略钻空子的风险,当前仅通过奖励项配比与判官多样性作有限缓解。

### 5.3 展望

其一,多智能体联合训练与跨智能体信用分配;其二,判官与策略的共同演化,以对抗奖励攻击;其三,将隐式几何物化的思路由"物化视图"推广至"物化相机轨迹",以获得更强的可控性。
