# 面向多镜头叙事视频生成的条件构造方法与策略优化

**实习工作总结**

---

## 摘要

多镜头叙事视频生成的核心困难,不在于单镜头的画质,而在于跨镜头的一致性:同一角色在不同镜头中长相漂移,同一场景换一个机位便成为另一个空间,镜与镜之间的硬切割裂了空间与时序的连续性。已有工作大多沿"增强模型"的路径求解——引入身份适配器、显式三维重建或相机可控模块,这类方案依赖对模型权重的干预,在以闭源 API 为视频后端的工程条件下难以落地。

本文提出一个不同的视角:**跨镜一致性问题的本质是条件构造问题**。每一镜生成什么,取决于我们向生成模型喂入了什么条件;因此一致性可以在不改动生成模型的前提下,通过"构造更对的条件"来获得。围绕这一主张,本文给出一条完整的解法链:条件的**素材**如何无中生有、条件的**记忆**如何跨镜跨片留存、条件的**决策**如何学会做对。

对应地,本文的三项工作是:(1) 提出**隐式几何物化**方法,利用视频扩散模型在预训练中已隐式习得的三维空间与镜头运动先验,通过定向摇镜自举出同一场景的多朝向视图,并通过双镜切换视频推理出切点之后的首帧,从而在不引入任何显式三维模块的前提下获得跨镜可复用的视觉锚点;(2) 设计**分层记忆系统**,将片内台账、在线增长的空间记忆与跨片的经验/技能记忆分层组织,支撑长片生成中的状态保持与经验复用;(3) 将逐镜的条件决策形式化为序贯决策问题,采用**组相对策略优化(GRPO)**,以文本判官与原生视频判官构成的结果型奖励进行训练,并针对视频域反馈昂贵、稀疏、高方差的特点,提出逐镜成组、镜间换脑的半在线训练架构。

〔待补:关键定量结果一句,例如一致性维度相对基线的相对提升〕

**关键词**:多镜头视频生成;跨镜一致性;条件构造;隐式几何物化;分层记忆;组相对策略优化

## 1 引言

### 1.1 研究背景与问题

视频生成模型在单镜头质量上已经取得显著进展,但**把若干个高质量镜头拼接起来,并不等于得到一部片子**。当生成任务从"一个镜头"扩展到"一段叙事"时,新的困难来自镜与镜之间,而非镜头之内。

在实际生成中,这些困难集中表现为四个方面:

**C1 空间不一致。** 每一次生成调用都是独立采样,模型不持有跨调用的持久三维场景表示。同一个房间,换一个机位就变成了另一个房间——墙的颜色、门的位置、家具的布局都可能改变。

**C2 时序断裂。** 镜与镜的交界处缺乏可用的过渡先验。若直接硬切,人物姿态与空间关系在切点处发生跳变;而这一跳变恰恰是观众最敏感的地方。

**C3 状态遗忘。** 一部长片所涉及的信息量超出单次上下文所能承载的范围;同时,一次生成中获得的经验无法在下一次生成中复用,系统不会随使用而变好。

**C4 决策组合爆炸。** 每一镜"该用哪些条件、提示词怎么写"构成一个巨大的组合空间:条件策略是离散的,参考素材的组合是组合式的,提示词本身则是连续的自然语言空间。手写规则难以覆盖长尾,而监督学习又缺乏标签。

已有工作对 C1、C2 的主流应对是**增强模型本身**:训练身份保持适配器、外挂三维重建以提供显式几何、或引入相机可控生成。这些方案的共同前提是可以干预模型权重或内部结构。在本项目的工程约束下——视频后端为闭源商用 API——这一前提不成立。

### 1.2 核心主张与技术路线

本文的主张是:

> **跨镜一致性问题可以重构为条件构造问题。** 生成结果的一致性,取决于喂给生成模型的条件是否正确;因此,与其增强模型,不如构造条件。

这一重构把一个"模型能力问题"转化为一个"系统设计与决策问题",并自然地分解为三个递进的子问题,构成本文的技术路线:

| 环节 | 待答问题 | 本文方法 |
|---|---|---|
| **素材** | 跨镜一致所需的视觉锚点从何而来? | 隐式几何物化:多视图空间锚定 + 镜间交界派生(第 2 章) |
| **记忆** | 锚点与历史决策如何跨镜、跨片留存与取用? | 分层记忆系统(第 3 章) |
| **决策** | 每一镜究竟该用哪些锚点、如何写提示词? | 组相对策略优化(第 4 章) |

其中前两环是**训练无关的系统设计**,第三环是全系统中**唯一引入学习**的部分。这一取舍本身是一个有意的设计决定:在一个由二十余个智能体协作的管线中,只有少数决策点同时具备"决策空间大"与"后果可客观测量"两个性质,值得付出训练代价。

### 1.3 主要工作与贡献

1. 提出**隐式几何物化**方法,论证并实现了"用视频生成模型自身的生成能力,把其内部隐式的三维几何先验物化为显式视觉锚点,再作为条件回灌"这一路径,避免了外挂三维重建模块。
2. 提出**在线增长的空间记忆**机制:每镜生成完成后,其尾帧经去人物处理与语义标注后回流为该场景的新视图,使空间表示随片长自动变得完备。
3. 将逐镜条件决策形式化为序贯决策问题,设计了与任务语义对齐的复合奖励(格式 / 文本判官 / 原生视频判官),并给出适配视频域反馈特性的**半在线 GRPO 训练架构**。
4. 给出一份**负面结果的根因分析**:以 vLLM 服务 LoRA 策略的方案在张量并行条件下整体失效,据此重构为本地推理架构。

## 2 隐式几何物化:多视图空间锚定与镜间交界派生

### 2.1 核心洞察

视频扩散模型在大规模预训练中已经隐式习得了三维空间与镜头运动的先验——它能够生成连贯的摇镜,也能够生成保持空间关系的镜头切换。既然这份几何知识已经存在于模型内部,那么:

> **我们不需要外挂显式的三维重建模块,只需要用模型自己的生成能力,把这份隐式几何"拍出来、定格成图像资产",再作为条件回灌给它自己。**

本文将这一路径称为**隐式几何物化(Implicit Geometry Materialization)**。它有两个具体实例:用摇镜物化"空间",用双镜切换物化"切换后的相机位姿"。二者共享同一份空间表示,并非彼此独立的技巧。

### 2.2 多视图空间锚定

给定一张空场的背景板,系统向视频模型发出定向摇镜指令,生成一对约 180° 的摇镜视频,再从中抽帧,即得到同一空间在多个朝向下的视图。每个视图由视觉语言模型标注一句**固定元素清单**(墙体、门窗、家具及其相对位置),该清单是后续视图选取与几何核验的唯一判据。

这一设计中有三处约束来自实测,值得记录:

- **背景板必须空场。** 若板上含有人物,该人物会污染后续所有以此视图为参考的生成结果,造成身份串扰。
- **图注刻意排除天色、光照与时辰。** 早期版本未作此排除,导致下游的几何核验将"红霞"与"橙蓝晚霞"判定为空间矛盾,连续三次拒绝了几何上完全正确的结果。**几何一致性与光照一致性必须解耦**,否则核验器会在错误的维度上行使否决权。
- **近重复视图需去重。** 以像素平均绝对差为判据剔除高度相似的视图,防止视图池被冗余样本撑爆而稀释有效朝向。

**在线增长机制。** 空间表示并非一次性构建后即固定。每一镜生成完成后,系统取其尾帧,经去人物处理与语义标注后,若不与已有视图重复,则**追加为该场景的新视图**。这构成一个自监督的记忆增长回路:片子拍得越长,该场景的空间表示越完备,后续镜头可选的锚点越多。

### 2.3 镜间交界派生

对相邻两镜,系统首先由一个判官智能体做三路分诊:依据上镜结尾与本镜开场各自的在场人物集合与场景标识,判定交界模式为**派生 / 硬切 / 延续**;该判定同时配有基于集合比对的确定性兜底。

在需要派生时,执行以下链路:

1. **上镜实况观测。** 由视觉语言模型读取上镜尾段,输出机位角度与各人物的实际动作。此处有一个重要的概念区分:**剧本所写的"结束状态"是意图,而尾段观测得到的是事实**;条件必须建立在事实之上,否则计划与执行的偏差会沿链路累积。
2. **双镜脚本生成。** 一个专职智能体依据上镜实况、本镜开场意图与选定的空间视图,写出一段"两镜……切至……"的双镜脚本。其输出须通过四级校验(非空、引用符号属于合法槽位、不含裸露人名、语言一致),失败则回退至确定性模板。
3. **切后首帧抽取。** 生成该双镜视频,定位切点,抽出**切点之后的第一帧**。这一步的实质是:我们并不显式计算"切换之后相机在哪、人物落在画面何处",而是**把这次空间推理外包给视频模型本身**,再把推理结果取回。
4. **几何核验。** 由核验环节比对该帧与选定视图的固定元素排布,天色光照一律豁免。核验采取**失败即放行**的策略:一个不完美的核验器若拥有否决权,其误拒代价大于其纠错收益;两次被拒才降级为硬切。

通过核验的帧作为"钉帧参考图"进入本镜的条件集合。

### 2.4 两者的耦合

派生时,选定的空间视图与其图注会一并作为参考喂入,使镜头切换发生在**已知的空间**之中而非凭空推演;而派生所得的尾帧又会回流补充该空间的视图池。二者因此构成一个闭环:空间表示支撑交界推理,交界结果反过来充实空间表示。

## 3 分层记忆系统

长片生成中的信息量远超单次上下文,且经验若不能跨次留存,系统便不会随使用而变好。本文将记忆按生命周期与用途分为四层:

| 层次 | 类比 | 内容 | 生命周期 |
|---|---|---|---|
| 工作记忆 | 手边便签 | 本镜上下文、上镜实况、可用槽位清单 | 单次决策 |
| 情景记忆 | 场记板 | 每镜的条件选择、评审结论、降级原因 | 一部片 |
| 空间记忆 | 场地图册 | 多朝向视图及其固定元素清单 | 一部片,**在线增长** |
| 语义-程序记忆 | 老师傅的经验 | 跨片经验、可回放的修复流程、跨片人物肖像 | 跨片,累积 |

其中两条设计原则具有一般性:

**其一,多智能体系统的状态必须外化到磁盘。** 情景记忆以台账文件为唯一载体,每一次状态变更即刻回写。状态若只活在进程内存中,则既不可恢复,也不可审计;而对于一次运行动辄数十分钟、消耗大量 API 调用的任务,不可恢复意味着任何异常都会造成全部损失。

**其二,自我改进必须带准入门槛。** 修复流程可被蒸馏为可回放的技能存入技能库,但须通过准入检验方可入库;同样,无评审的运行不得写入跨片记忆——缺乏可信成败标签时,宁可不记。若无此门槛,系统会把偶然的成功固化为教条,记忆反而成为性能的拖累。

## 4 面向条件构造的组相对策略优化

本章是本文的核心技术工作。

### 4.1 为什么必须引入学习

全系统包含二十余个智能体,但只有**逐镜条件决策**这一个环节被选作可训练策略。这一选择是逐层排除的结果:

**为什么是这个决策点?** 它同时满足三个条件:决策空间大且组合化;决策后果**可被下游客观测量**(视频真的生成出来了,判官可以打分);信用分配清晰(该镜的好坏主要由该镜的条件决定)。其余智能体或决策空间过小(如三选一的交界分诊),或后果不可直接测量(如剧本质量),均不适合作为策略。

**为什么手写规则不够?** 该决策的动作空间是"离散策略 × 参考素材组合 × 自然语言提示词"的混合空间。本项目为此编写的技能文档已逾两百行,仍持续暴露长尾失效。

**为什么监督微调不行?** 因为没有标签。"什么是正确的条件选择"这一问题,**只有把视频真的拍出来才知道答案**;任何离线人工标注都是在猜测。这是引入强化学习的决定性理由。

**为什么是 GRPO 而非 PPO?** PPO 需要价值网络,而本任务的奖励昂贵(每个样本需真实生成视频并调用多个判官)、稀疏(一镜一个标量)、高方差。在可获得的数据规模下,价值网络难以训练,反而引入偏差。GRPO 以**组内相对比较**替代价值网络:在同一状态下采样 K 个候选,组均值天然构成该状态的基线。这一替代同时消除了"该镜本身难易"的偏置——难镜的候选普遍得分低、易镜普遍得分高,而**相对优势不受影响**。这是 GRPO 契合本任务的最本质原因。

**为什么必须是半在线?** 一次视频生成耗时数十秒至数分钟,严格在策略采样在算力上不可行;而完全离线又将面临分布漂移。折中方案是:**逐镜成组、镜间换脑**——组内严格同策略,组间允许有限滞后,由重要性比值与陈旧度过滤共同控制偏差。

### 4.2 问题形式化

决策过程具有三层结构:一个 **episode** 是一部片(T 个镜头),一个 **step** 是一镜的条件决策,而一个 **action** 是策略产生的一段 JSON,即一串 token。

- **状态** $s_t$ 包含镜头表条目、人物设定、选定空间视图、上镜实况、交界结果、图像计划、槽位清单,以及依据后端能力动态生成的策略菜单 $\mathcal{M}_t$;
- **动作** $a_t=(c_t,\,p_t)$,其中 $c_t\in\mathcal{M}_t$ 为条件策略,$p_t$ 为视频提示词,二者由策略以**单条 JSON 序列** $y_t$ 一次性产生;
- **转移**:调用视频后端生成片段,更新台账与空间记忆,得到 $s_{t+1}$;
- **奖励** $r_t$ 为结果型奖励,见 4.3。

需要指出:动作是 token 序列,故策略梯度作用于 **token 级**,而奖励只在 **step 级**给出。GRPO 通过将 step 级优势广播至该序列的全部 token 来处理这一稀疏信用分配。

### 4.3 奖励设计

总奖励由三部分复合:

$$
r \;=\; 0.15\,r_{\text{format}} \;+\; 0.35\,r_{\text{text}} \;+\; 0.50\,r_{\text{video}}
$$

**格式奖励** $r_{\text{format}}\in[0,1]$ 与生产管线的校验闸门刻意同构:JSON 可解析 0.4,所选策略在菜单内 0.2,引用符号属于合法槽位 0.2,语言与项目一致 0.1,必填字段齐全 0.1;若管线已判定该输出不可用则直接计 0。

此处有一个值得记录的**奖励攻击**观察:格式奖励占比若设置过高,策略会学会输出"格式完美但内容空洞"的提示词以套取分数。这说明形式合规性只能作为门槛项,不能作为主要激励。

**文本判官奖励** $r_{\text{text}}$ 由文本模型依据评分技能对单个候选打四维分:剧本忠实度、视觉具体性、交界连续性、人物纪律。其中**交界连续性是条件维**——硬切本就不欠连续性,对其强行评分等于惩罚一个正确的决策,故该维在不适用时判空,总分按有效维归一。这体现了一条原则:**奖励必须与任务语义对齐**。

**视频判官奖励** $r_{\text{video}}$ 由多模态模型以**原生视频输入**(不抽帧)给出,含四个分量:

$$
r_{\text{video}} \;=\; \frac{0.30\,s_{\text{act}} + 0.25\,s_{\text{phy}} + 0.15\,s_{\text{cam}} + 0.30\,s_{\text{cons}}}{\textstyle\sum \text{有效权重}}
$$

前三维(表演、物理、运镜)采用**组内排名**而非绝对打分:一组候选一次调用完成排序,展示顺序随机打乱以消除位置偏好,允许并列;排名转点数后归一。第四维(一致性)则采用**对照清单直判**。这一区分是有意的:**当组内候选全部质量低下时,排名会把"矮子里的将军"当作好样本**;凡是存在客观锚点(参考图、布局清单)的维度,必须使用绝对判定而非相对排序。

**诚实降级。** 任一判官失败时,剔除该分量并对其余权重重新归一化,同时留痕;全部失败则退回旧版指标。**绝不以 0 分冒充评审结果**——0 分是一个强信号,会严重污染优势估计。

### 4.4 组相对优势与主干选择

对状态 $s_t$,从采样时策略 $\pi_{\theta_{\text{old}}}$ 采出 K 个候选并获得奖励 $\{r^{(i)}\}_{i=1}^{K}$,组相对优势为

$$
A^{(i)} \;=\; \frac{r^{(i)} - \bar r}{\sigma + \epsilon},
\qquad
\bar r = \frac{1}{K}\sum_{i} r^{(i)},
\quad
\sigma = \sqrt{\frac{1}{K-1}\sum_{i}\bigl(r^{(i)}-\bar r\bigr)^{2}},
\quad
\epsilon = 10^{-6}
$$

三处实现细节:标准差取无偏估计,且不采用留一法(样本自身亦在其基线之内);若组内奖励打平($\max_i|A^{(i)}|<10^{-6}$)则**整组跳过**,因为此时梯度精确为零,执行优化步只会累积数值噪声;$K=1$ 时优势定义为 0。

**主干选择。** 与标准 GRPO 不同,本文的轨迹推进方式为

$$
s_{t+1} \;=\; \mathcal{T}\bigl(s_t,\; y^{(i^\star)}\bigr),
\qquad
i^\star = \arg\max_i\, r^{(i)}
$$

即每一步在产生一个完整比较组的同时,沿当前策略的最优分支推进轨迹。

这一设计引入了状态分布偏置——采样到的状态偏向高奖励区域,与均匀在策略分布不同。对此的辩护是:**部署时系统本就采用贪心解码,因此该偏置的方向与部署时的状态分布是一致的**,属于有意为之而非疏漏。

### 4.5 策略目标

记 token 级重要性比值

$$
\rho^{(i)}_{l}(\theta)
=\exp\Bigl(\log \pi_{\theta}\bigl(y^{(i)}_{l}\mid s,\,y^{(i)}_{<l}\bigr)
-\log \pi_{\theta_{\text{old}}}\bigl(y^{(i)}_{l}\mid s,\,y^{(i)}_{<l}\bigr)\Bigr)
$$

策略梯度损失采用**非对称裁剪**:

$$
\mathcal{L}^{\text{PG}}(\theta)
=-\frac{1}{\sum_{i}\lvert y^{(i)}\rvert}
\sum_{i=1}^{K}\sum_{l=1}^{\lvert y^{(i)}\rvert}
\min\Bigl(
\rho^{(i)}_{l}A^{(i)},\;
\operatorname{clip}\bigl(\rho^{(i)}_{l},\,1-\varepsilon_{\text{low}},\,1+\varepsilon_{\text{high}}\bigr)A^{(i)}
\Bigr)
$$

取 $\varepsilon_{\text{low}}=0.2$、$\varepsilon_{\text{high}}=0.3$。上下界不对称的用意是:为正优势 token 保留更大的上升空间,以缓解熵坍缩,防止策略过早收敛到单一表述。

KL 正则采用 k3 低方差估计量。令 $\Delta^{(i)}_{l}=\log\pi_{\text{ref}}-\log\pi_{\theta}$,则

$$
D^{k3,(i)}_{l}=\exp\bigl(\Delta^{(i)}_{l}\bigr)-\Delta^{(i)}_{l}-1\;\ge\;0
$$

$$
\mathcal{L}(\theta)=\mathcal{L}^{\text{PG}}(\theta)
+\beta\cdot\frac{1}{\sum_{i}\lvert y^{(i)}\rvert}\sum_{i,l}D^{k3,(i)}_{l},
\qquad \beta=10^{-3}
$$

三点说明:KL 作为**损失项**而非并入奖励,后者会污染组内相对比较;k3 估计量恒非负且方差低;聚合方式为 token 级平均(按组内总 token 数归一),而非序列级平均,否则长序列会被系统性低估。

**参考策略的免费获取。** 由于策略以 LoRA 形式训练,关闭适配器即精确等于基座模型:

$$
\pi_{\text{ref}} \;=\; \pi_{\theta}\big|_{\text{adapter disabled}}
$$

因而**无需保存第二份权重,也无需独立的参考模型进程**——主流实现通常需为此单独启动一个分布式 worker。

### 4.6 行为策略保真度

以下三条源自实测踩坑,对复现者具有直接价值:

**其一,训练与采样必须使用同一串 token。** 采样时记录 prompt 与 response 的 token 序列,训练时直接复用,绝不以文本重新分词。早期版本在训练端对裸文本重新分词且未套用对话模板,致使梯度作用在模型从未见过的序列上。

**其二,温度必须同样作用于训练时的对数概率**,即 $\log\pi_\theta(y_l\mid\cdot)=\log\operatorname{softmax}(z_l/T)[y_l]$。

**其三,真实行为分布必须可解析表达。** 采样时强制 $\text{top}_p=1$、$\text{top}_k=0$,使行为策略精确等于 $\operatorname{softmax}(z/T)$。一旦采用截断采样,所记录的 $\log\pi_{\theta_{\text{old}}}$ 便不再是真实行为概率,重要性比值从根本上失效。

此外,前向计算仅保留 completion 位置的 logits,使单条序列的相应显存占用由约 9.2 GB 降至约 0.7 GB。

### 4.7 系统实现

**架构。** N 条采样流各独占一张显卡执行本地推理,一个训练器独占一张显卡;两者之间以两条**文件通道**通信——组队列与适配器广播。采用文件而非共享内存的理由是:各进程独占显卡、无法共享 Python 对象,而文件通道具备崩溃可恢复、可人工检查、无需额外守护进程三项优势。其代价是必须自行处理原子性(先写临时文件再改名)、一次性消费(先认领再加载)与磁盘上限(适配器仅保留若干代、队列消费即删)。

**广播节拍与陈旧度。** 每 B 次优化步发布一版适配器(B 为超参)。定义组的陈旧度为发布版本与该组采样版本之差,超出阈值的组直接丢弃。此外有一条**正确性要求**:适配器的重载只允许发生在镜与镜之间。若在组采样中途换脑,一个组将横跨两个策略版本,组内相对比较随之被污染,而这种污染在日志上不留任何异常痕迹。

**训练与生产的同构锁。** 训练环境是生产管线的逐字移植,由函数级与文件字节级的自动化检验共同守护,两者差异被限制在一张可枚举的清单内(关闭修复循环、替换判官、关闭跨片记忆、启用 K 路采样)。这一机制的论点是:**离线训练环境与在线部署环境之间的任何静默漂移,都将使训练收益无法迁移**,因此二者的一致性必须机器可验,而非依赖人工纪律。

### 4.8 负面结果:以 vLLM 服务 LoRA 策略的失败诊断

初期方案采用推理服务框架加载 LoRA 适配器对外提供策略服务,该方案整体失效,其诊断过程如下:

- **现象。** 基座模型的决策全部可用,而所有适配器版本的可用率为零;全部由策略驱动的角色**同时**失效,而使用冻结模型的智能体保持完全健康。
- **定位。** 上述对照将故障范围限定在**被服务的策略**本身,而非提示词、技能文档或解析逻辑。进一步检查原始输出,发现其自第一个 token 起即为多语言混杂的无意义串。
- **归因。** 该现象与推理框架在"LoRA 与张量并行同时启用"条件下的已知缺陷相符。
- **处置。** 重构为本地推理架构,从根本上移除该类风险。

诊断过程中另发现三处独立缺陷:条件优先级表遗漏某策略,导致本应锁定的菜单静默失效;训练目标在兜底路径下退化为固定字符串,致使梯度恒为零;以及前述训练端重新分词问题。

## 5 工作总结与展望

### 5.1 工作总结

本文围绕"多镜头叙事视频生成中的跨镜一致性"这一问题,提出将其重构为**条件构造问题**,并沿"素材—记忆—决策"三环给出了完整解法:以隐式几何物化自举出跨镜可复用的视觉锚点,以分层记忆支撑长片的状态保持与经验累积,以组相对策略优化训练逐镜条件决策。全系统在不干预视频生成模型权重的前提下运行,适配闭源商用后端。

### 5.2 局限

- 隐式几何物化依赖视频模型自身的几何先验,当该先验在特定场景下失效时,自举出的视图本身即不可靠,而当前的核验环节采用失败即放行策略,难以完全拦截此类情形。
- 训练目前仅覆盖单一决策点,其余智能体保持冻结;多智能体联合训练下的信用分配尚未处理。
- 判官本身是被优化的对象所面对的环境,存在被策略钻空子的风险,当前仅通过奖励项配比与判官多样性作有限缓解。

### 5.3 展望

其一,多智能体联合训练与跨智能体信用分配;其二,判官与策略的共同演化,以对抗奖励攻击;其三,将隐式几何物化的思路由"物化视图"推广至"物化相机轨迹",以获得更强的可控性。
