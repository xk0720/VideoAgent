五 训练环境少了哪几段

rl/env/ 是这条线的逐字移植。不一样的只有下面这些,其余每一段完全相同。

组件生产RL 训练为什么
修复循环(整理员 + 调度 + 验收官)开,3 回合关训练要的是"第一次就写对"的信号,修复会把它洗掉
语义/物理评审开换成奖励判官训练用自己的 VLM 评分 skill
锦标赛开(n=1 空转)关胜者 = 组内奖励最高者
跨片记忆开关不让历史片子污染同分布采样
润色师 / 过渡桥 / 配乐 / 基线锚点按需开全关不在训练路径上,纯成本
一镜采 K 个候选没有RL 专有GRPO 的组来源
