# 周报小结 — Agent 循环 与 Memory 贡献

## 一、主体 Agent 循环逻辑

整个系统是"**大循环套小循环**":大循环负责把一部完整视频一镜一镜地生产出来,小循环负责把每一镜修到过关。

**大循环:窗口式全片生成**(`pipeline/window_loop.py` 的 `generate_movie_windowed`),五步:

1. **写剧本**:用户一句话 → 编剧/导演 agent 拆成按时间顺序的分镜列表(每镜一句描述),同时建立分镜台账(见第二部分)。
2. **备关键帧**:brain 给每个镜头从菜单里选一种关键帧来源——文生图、用户素材图、用户视频抽帧、或者不用。菜单是**门控**的:没有的能力、没有的素材,选项根本不出现,brain 永远选不到执行不了的东西。
3. **逐镜搭条件生成**:每次只生成"下一个还没生成的镜头"。brain 决定怎么给生成模型"搭条件",共 7 种策略,核心思想是**利用上一镜已经生成好的内容当锚**:比如拿上一镜的最后一帧当本镜第一帧(画面无缝接上)、上一镜尾帧+本镜关键帧首尾双锚、上一镜结尾一小段视频当"运动参考"(让模型看着上一镜的动作接着拍)、两张图一起喂(上镜尾帧定起点+关键帧定目标画面)等。
4. **每镜过小循环**(`pipeline/generate_loop.py` 的 `generate_shot_orchestrated`):生成 → **评审**(VLM 评语义/角色/物体,非 AI 的物理测量链评运动是否符合物理定律,且都要给出"第几帧到第几帧有问题") → **整理员**把所有评审意见合并成一份排好优先级的简报 → **brain 读简报后从 12 个修复工具里挑一个**(局部重生成、就地编辑、关键帧修改后向下游传播、物理仿真出正确运动当参考等) → **Verifier 闸门**只接受"确实变好"的结果,被拒的动作记下来,brain 下回合不许重复。修到评审全过或回合用尽为止。
5. **合成**:所有镜头按时间顺序 ffmpeg 拼成成片。

**贯穿的三条设计原则**:
- **brain 提议、闸门裁决**——LLM 负责选,确定性规则负责把关,LLM 出错不会污染结果;
- **决策三层回退**——先查历史经验能不能直接照抄(不花 LLM),再让 LLM 选,LLM 输出垃圾就走确定性兜底,循环永远不会卡死;
- **一切留痕**——每个决策是谁做的(经验/LLM/兜底)、执行中有没有降级、降级原因,全部写进台账,可审计。

## 二、Memory 部分的贡献

我们的记忆分三层,各管一个时间尺度,**核心贡献是"记忆的可执行化":存的不是文字回忆,而是能直接驱动下一次决策的结构化数据——检索到就能直接用**。

1. **分镜台账 StoryboardMemory**(`memory/storyboard.py`,单任务内的短期记忆)
   按时间顺序给每个镜头记一条账:文字描述、关键帧(路径+来源)、视频路径、状态(待生成/已生成/已过审)、用了什么生成条件、**追加式的评审轨迹**(每次评审一条,从不覆盖)、修复动作流水。每次更新立即落盘成 `storyboard.json`。它是 brain 的"眼前有什么"——每个决策都以它为依据,跑完也能逐镜复盘。

2. **修复技能库 SkillLibrary**(`memory/skill_library.py`,跨任务,管"这类缺陷怎么修")
   一个缺陷被修好后,把"缺陷特征 → 被闸门验收过的工具序列"蒸馏成一条可重放的技能。下次遇到相似缺陷,**先重放技能、修不动再让 LLM 重新推理**。技能有完整生命周期:蒸馏 → 准入审查 → 检索 → 使用记账 → 打分 → 淘汰。(对比:同类工作 UniVA 的修复流程是人手写死的,我们的是学出来的。)

3. **情节记忆 EpisodeMemory**(`memory/episode_memory.py`,跨任务,管"这类任务怎么排产")
   一部片子做完,自动蒸馏成一条 good/bad 案例,里面是两张表:
   - **replay 表**(成功面):每个过审镜头用的"关键帧策略+条件策略"。下次接到相似任务,直接照抄这套打法(决策标记 via=episode,一次 LLM 都不用调);
   - **avoid 表**(失败面):没修好的镜头用过的策略+失败原因,注入 brain 的提示当禁令。

   good/bad **完全由客观结果判定**(全部镜头过审=good),不让 LLM 自评;执行中的降级(比如策略调用失败退回纯文本)必须如实记录,避免"把降级当成 brain 的选择"污染长期记忆——这样积累的经验才可信。

一句话总结:**短期台账让 brain 看清眼前,技能库让修复越修越熟,情节记忆让排产越排越准——三层都是"拿来即用"的结构化经验,而不是需要再理解一遍的文字。**
