# 音乐与音画同步接入方案(2026-07-28,dev-music,待用户裁决)

> 用户令:思考如何加音乐——背景音乐 + 可能的音画同步(角色说话),
> 重点参考 CutClaw 与其他含音乐编辑的开源项目。四路调研原文在
> `music_appendix/A-D`(CutClaw 精读 / 本地仓音频家当 / 音乐层选项 /
> 对白与口型)。**本文档是提案,未改代码。**

## 〇、三个改变设计的核心发现

1. **Seedance 2.0 原生音频是免费的**。WaveSpeed 的 seedance 端点
   (t2v/i2v/video-extend 全部)暴露 `generate_audio` 布尔参数,开启
   **不加价**(计价只按尺寸/时长/数量)。产物四层:对口型的台词
   (prompt 引号台词驱动口型)、帧准的音效、环境声、纹理级配乐。
   我们现在每次调用都主动关着它。
2. **video-extend 会保留并延续音频**(官方文档:"原片音频保留,新段
   原生生成")——音频跨镜连续性的机制恰好就是我们已有的 extend 链;
   而首帧条件(i2v/pin)携带零音频上下文,**跨镜同一角色会换嗓子**
   (Seedance 无声音克隆,社区确认)。
3. **成片级 BGM 必须后期做,而且我们方向和 CutClaw 相反**:它是
   "剪辑就音乐"(切点=节拍点,构造性同步),我们的切点由剧本定死,
   应当"音乐就剪辑"。恰好 WaveSpeed 有 **sonilo/video-to-music**:
   喂成片、出按节奏与转场贴合的配乐,$0.009/秒(27 秒片 ≈ $0.24),
   同一把 API key。

## 一、CutClaw 拿来什么(方向相反但零件可用)

CutClaw(GVCLab,arXiv 2603.29664)核心:madmom 强拍网格 + aubio
音高/能量峰 → NMS+归一化+复合分 → LLM 做曲式分段(Intro/Chorus/
Drop…)边界吸附到节拍点 → **每个音乐子段=恰好一镜,镜长强制等于
子段长**(±1s 容差)→ ffmpeg 双 stem loudnorm + amix + 时间窗闪避。
可搬的零件:① 信号栈整体可抬走(本地 CPU 免费,madmom 需其仓里的
兼容补丁);② "镜尾微裁几百毫秒把切点吸到最近强拍"的对齐法
(它的 snap 函数逻辑直接复用);③ ffmpeg 混音配方。诚实局限:它不选
曲不生成曲、无语音无口型、"同步"=切点放置(无量化音画对齐)。

## 二、两条线的设计

### 线 A:背景音乐(全在拼装阶段,管线主体不动)

```
现状:逐镜视频 → ffmpeg concat(纯视频)→ 成片
改后:逐镜视频(带原生音轨)→ concat(视频+音频)→
      ① 出 BGM:首选 sonilo/video-to-music(喂成片,自动贴节奏;
         备选 ace-step-1.5 文本生成(<$0.02/分钟,brain 按剧情弧线写
         mood/BPM 提示);兜底 Pixabay 免费曲库)
      ② 混音:sidechaincompress 闪避(BGM 压到对白下 18-20dB,
         attack 200ms / release 500ms —— OpenMontage 实测参数)
      ③ 两遍 loudnorm 收口(-14 LUFS / TP -1.5,平台标准)
```

- 剧本阶段加**音乐计划**(OpenMontage 的"音乐计划强制在提案期定"
  纪律):brain 按幕写 {mood, BPM 区间, 何处静场},人不再事后补。
- 可选抛光(M3):CutClaw 节拍栈,镜尾微裁吸附强拍——收益中等
  (切点已定,只能微调),依赖重(madmom 无人维护),放最后。
- 新增成本:每片 < $1。

### 线 B:对白与口型(生成时免费拿,后期只兜底)

- **主路线 = 原生引号台词**:剧本写 `角色 says: "台词"`(每句 ≤6 词,
  嘴型按引号串驱动——OpenMontage 生产知识原文);贴士全部进 skill:
  近景+正脸口型才准(远景嘴部分辨率不足)、非英语要注明语言、混音
  平衡用文字声明("对白清晰突出,音乐低")。
- **换嗓子问题的三重缓解**:
  1. ViMax 实证的做法:**每镜逐字重复同一段嗓音描述**("低沉的
     男声,微哑,慢条斯理")——嗓音进 cast 契约(声音半句);
  2. 连续对白镜**优先走 extend 链**(音频保留+延续,官方保证);
  3. 兜底:静音原生台词,TTS 配音(固定 voice id = 完美一致,
     整片对白 < $0.25)——但**没有任何托管工具支持给动物做事后
     口型**(sync.so 文档明说不支持非人形),所以 TTS 兜底时台词
     改画外音/旁白形态,不硬贴嘴。
- **猫会不会对口型是最大未知数**(所有口型质量报告都是人脸),
  必须先做验证实验(见 M0)。
- OmniHuman 1.5(声称支持宠物,$0.16/s)登记为"对白特写镜"备选:
  它是图+音频→视频(整镜重生成),破坏尾帧续接,只适合插入镜形态
  ——与 narrative_cut 逃生门天然互补,登记不实施。

### 评审与台账同步

- 评审加音频检查项(对白在不在/清不清楚、口型贴不贴、音效合不合理)
  ——Gemini 原生视频输入本来就带音轨(+32 token/秒,便宜);
- 台账逐镜记 {有无对白, 台词, 嗓音描述, 音频层验收结果}。

## 三、分阶段实施

- **M0 验证实验(先花小钱定生死,三个 playground)**:
  1. 猫 + 引号台词:近景猫说 4-6 词,看嘴动不动、动得贴不贴;
  2. extend 链音频:上镜带台词,extend 续 5 秒,听声音/配乐是否
     连续、换不换嗓;
  3. 全链路:attempt3 成片(已有!)→ concat 带音轨 → sonilo
     video-to-music → 闪避 → loudnorm,直接听效果。三个实验总成本
     约 $2-3。
- **M1 原生音频接通**:`generate_audio` 参数化(默认开)、concat 改
  音频安全(-c:a aac,流对齐)、scene_write/enhancer skill 加台词与
  嗓音条款、台账字段。
- **M2 BGM 拼装阶段**:音乐计划入剧本、sonilo/ace-step 双路 + 闪避
  + 两遍 loudnorm、评审音频检查项。
- **M3 可选抛光**:节拍吸附微裁、嗓音一致性升级、音频缺陷进修复
  菜单(重配音轨 vs 重生成的分诊)。

## 四、待裁决与诚实边界

1. M0 三实验先跑?(强烈建议——猫口型是整条线 B 的分水岭)
2. BGM 首选 sonilo video-to-music(自动贴合、稍贵)还是 ace-step
   (更便宜、靠 brain 文字描述)?建议 M0-3 先试 sonilo 听效果。
3. 原生台词的"换嗓子"风险在多镜对话里无法根除(只能缓解)——
   若你的片子以对白为主,TTS+画外音形态更稳,请定基调。
4. 修复循环与音频的交互是新的复杂度:重生成一镜会换它的音轨
   (M1 先接受,M3 再做分诊)。
