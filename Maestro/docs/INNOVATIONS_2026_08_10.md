# Maestro 创新技巧总览(2026-08-10)

> 范围:window 管线(三条件融合派)+ 空间圣经 + 六人剧组 + 全部确定性闸门。
> 对照基线:`--mode cinegraph`(严格 ViMax 移植)与 `scripts/naive_baseline.py`(纯文字直拼)。
> 核心哲学一句话:**一致性不需要"真",只需要"唯一"**——把所有"现场脑补"
> 前移为"资产期一次定稿",生成期只许引用,绝不重新发明。

---

## 一、六人剧组(独立 agent 编成)

每个角色是**独立 LLM/VLM 实例**(`models.crew.<role>` 可逐角色换模型),
绝不共享对象——职责单一,失败可归因:

| 角色 | 底座 | 职责 | 技能文件 |
|---|---|---|---|
| 剧本扩写 screenwriter | LLM | 用户输入 → 完整剧本 | screenplay |
| 分镜 scene_writer | LLM | 剧本 → 分镜台账(强 JSON) | scene_write |
| 视频 brain video_brain | LLM | image_plan / 条件策略 / 修复决策 / 机位树 / 判官 / 挑图 | window_generation, image_plan, orchestrator |
| 润色 prompt_enhancer | LLM | 承接润色 + 引用形式化 | prompt_enhancer |
| **缝合师 junction_stitcher** | LLM | 交界派生的两镜描述(新) | junction_stitch |
| 评审 reviewer | VLM | 语义/物理评审、图注、片尾报告 | semantic_critic |
| 验证 verifier | VLM | 修复后终验(独立通道) | — |

**创新点**:agent 只出"品味"(散文描述、策略选择),**契约全部机器锁死**
(骨架模板、槽位编号、语义行、清洗、校验闸)。所有 agent 坏输出都有
确定性退化路径,管线永不因单个 agent 断链;每次调用 `brain_calls.jsonl`
落盘(为 RL 攒 (状态,动作,结果))。

## 二、总 agent loop(window 管线)

```
§A 剧本层
  用户输入/剧本 JSON → screenwriter 扩写
  → 语言判定(全局 output_lang,先于一切打标)
  → 钦定角色在场闸(剧本没这个名字 → 拒绝绑定)
  → character_extract(名字语言法 + 纠错重试)
  → scene_write 分镜(七道确定性闸门,见 §四)
  → 台账 StoryboardMemory 落盘(单一事实源)

§A' 资产层(First 保障:缺一不开拍)
  人物:官方肖像(用户图 > 跨片库 > t2i)逐镜断言
  背景:视区法分 bg_id → 每 id 一张空景主板(地标覆盖法)
  空间圣经:每 bg 环视视频抽帧建多视图池(见 §五)
  逐镜资产闸:任何镜缺人物图/背景板 → 点名报错停跑

§B' Image Plan
  brain 逐镜决定 0-2 张关键图(数量/角色/来源),降级留痕

§C+§D 逐镜大循环
  交界三叉分诊(见 §三)
  → 条件策略(菜单按交界锁定;槽位清单 = 单一事实源)
  → brain 起草 prompt → enhancer 润色(语言拒收闸)
  → 出口清洗链(剥标记/正典标签/建景句/旁白/名字终换/引用校验)
  → 机器承接句(pin 行 → "画面从<<<image_K>>>所示的首帧继续")
  → 音频法(台词逐字 + 压制句 + 哑镜保险)
  → 可灵生成(refer 装配与清单 1:1)
  → 评审/修复(可总开关关闭;修复线含段修自锚、重掷 pin 句回注)
  → 收货 → 空间圣经清场回流(实拍帧入池)

§E 拼装:时长对账 → normalize → concat;§F 配乐;§M 蒸馏 episode
```

## 三、三条件融合派(交界路由,核心创新)

**问题**:镜与镜的接缝是一切不一致的源头。旧钉帧派(上镜末帧硬钉首帧)
在人物/场景变化时必然"原地变形换人"。

**分诊器**:每个交界先由**LLM 判官**推理"实际在场"人物集合——不是数
文字提及("上镜只写了<小明>在哭"≠画面里只有小明,两人可能同车全程),
坏输出退化为确定性集合比对(同脸不同名按肖像路径判等)。再比 bg_id:

| 交界 | 路由 | 缝法 | 失败退化 |
|---|---|---|---|
| 人物变 | **derive** | ViMax 双镜派生缝合 | cut |
| 同人 + 异景 | **cut** | 纯 ref2v 硬切(人物+新景板引用强制) | — |
| 同人 + 同景 | **derive** | 同景派生(视角可能变,3D 感知接管) | continue(片尾报告文字承接) |

**创新点**:
1. **判官思考在场性**而非文字匹配(业界通行做法是启发式 diff);
2. **同景也派生**(2026-08-09 裁决):背景一样≠视角一样,双镜的 3D
   感知负责换角度;同景派生**不挂背景板**(板与运镜打架);
3. 每条路的完整档案落台账 `junction_meta`(kind/理由/挑图/缝合师
   产物/派生工件/降级),事后可全链审计。

### 派生缝合链(ViMax two-shot 的五点强化)

ViMax 原版:父帧一张 refer + 纯文字两镜描述 + scenedetect 切帧,直接采用。
我们的版本:

1. **多参考**:`[上镜真实末帧, 出场人物肖像…, 朝向视图/新景板]`——
   原版新人长相靠瞎想,我们把长相与空间钉死;
2. **记号语义**:每张参考在 prompt 里有名有姓(`<<<image_1>>> is the
   exact frame…`,肖像带防拷贝子句,视图带布局法);
3. **缝合师 agent 组稿**:第一镜以 VLM 片尾报告为准(实拍压过剧本),
   第二镜提炼"切后第一眼"(人物/场景全记号指称);四级校验
   (格式/记号契约/内容纪律/语言)→ 纠错重试 → 模板装配退化;
4. **MAD 切点检测**(免 scenedetect 依赖)+ **只认矛盾的帧审查**
   (图注是有损摘要,"没提到"不是罪证;两拒换 seed 一次,再拒降级);
5. **派生帧走 refer 通道**(非 API 硬钉):挂末位 refer + 机器承接句,
   与钉帧的记号机制统一。

## 四、分镜层确定性闸门(每道都有事故编号)

分镜是全片的 DNA,scene_write 输出要过七道闸,**坏回复预算与语义纠错
预算分开记账**(空回复不吞掉闸门的纠错机会):

| 闸门 | 防什么(事故) |
|---|---|
| 语言闸 | zh 项目分镜写成英文(run11) |
| 台词覆盖闸(逐字且完整) | 台词截半"大海真大啊。"(xiaoming run2);dict/str 双形态 |
| 声效覆盖闸(全文直查+剧本词典) | "雨滴敲击车窗声"被改写丢失(rainnight run3);句中嵌入误报(cinegraph run3) |
| cast 键语言法 | 派生角色被起名 "the gunman"(rainnight run2) |
| 视区法 bg 分配 | 店外立面和店内柜台折进一个 id → 店内 5 镜五间店(面包店事故) |
| CAMERA FACING 字段 | 挑视图无证据 → 全退 master(天台) |
| 人物写进每字段 | 只写运镜的镜丢人物 → 引用链断 |

**创新点**:`camera_facing` 是**选图专用证据字段**——永不进任何生成
prompt(误导归零),只流向挑图判官与台账;description 保持纯戏剧内容。

## 五、空间圣经(Space Bible,背景一致性体系)

**洞见**:人物一致性早已解决(定妆照体系),空间从未享受同等待遇——
每镜现场脑补房间,一镜一个样。空间圣经与人物体系逐层同构:

| 人物体系 | 空间体系 |
|---|---|
| 正/侧/背定妆照 | **多视图注册表** `spaces{bg:{view:{path,caption,src}}}` |
| 侧脸镜挑侧面照 | **按 camera_facing 挑朝向视图**(图注语义匹配) |
| — | **布局法语义行**:"固定元素位置外观必须与此图一致;光线天色随剧情;构图自由" |
| ViMax 帧历史池 | **清场回流**:收货帧 → seedream 擦人 → 图注验收(还有人→弃)→ **纯追加**入池 |
| 帧审查矛盾法 | **LAYOUT LAW 审查**:派生帧 vs 视图图注,只判空间排布,天色豁免 |

**视图生成术的演进**(三代,各自的失败教训):
1. seedream 逐视图编辑 → 图像编辑无 3D 场景理解,"店的左边"是另一家店的左边(废弃为兜底);
2. 单段 360° 环视视频抽帧 → 首帧硬钉主板,视频通道 3D 一致性保真;但 "Locked-off" 行话自相矛盾(=完全固定机位)、指令埋在 120 词场景后、36°/秒甩镜全糊;
3. **现行:左右各 180° 两段**(18°/秒锐利、纯旋转、段间独立),镜头指令置顶、显式禁 dolly/orbit、删"回到起点"偷懒许可证;每段 50%/96% 抽帧。

**入池纪律**:环视是**采样器不是量角器**——每帧与 master/已收帧做
MAD 独特性验收(<12 判重丢弃留痕);图注用**清单式指令**(固定物+方位,
不写氛围概括——通用图注把四个朝向写成同一句);**以成品为准**,不信
转向指令。

**回流优先级**:实拍 > 脑补;按用户裁决**纯追加**(错误追加无害,
错误顶替有毒)。

## 六、prompt 纪律(引用铁律与机械路径治理)

1. **槽位清单 = 单一事实源**:执行器装配顺序与清单逐行 1:1(契约测试
   锁死);写手引用编号只许照抄清单,越界引用整稿拒收;
2. **名字终换闸**:引号外裸名 → 记号,台词引号内原样(口型对准真人);
3. **机器承接句**:凡清单有 pin_frame 行(钉帧/派生帧),机器前置
   "画面从<<<image_K>>>所示的首帧继续",写手绝不自行提及;重掷同句回注;
4. **共用清洗器** `_scene_text_for_prompt`:一切机械搬运路径(派生双镜
   描述/重掷锚句)共享——剥 Shot 前缀/旁白(带引号与无引号两形态)/
   音效标注/纯声词句/收尾标点;**声词嵌在动作句里不动**(只删纯声词句);
5. **锚句纯散文法**:"本镜剧本动作:/收束为:"等人读标签是给人看的注记
   语言,不是画面语言——全部废除,重掷锚句与主链同为散文;
6. **音频法**:台词逐字直落 + 每镜压制句(有台词只许人声+剧本环境声/
   无台词只许环境声,恒无 BGM——BGM 由 §F 统一配)+ 哑镜保险
   (prompt 含言说句但 dialogue 空 → 照开原生音频);
7. **板磁铁法**:挂了 pin 行的镜剔除背景板 refer(空板会把画面吸成
   无人板本体);E 案:锚定路线不复述正典(稀释钉帧)。

## 七、可靠性与可审计性

- **传输层重试**:LLM 客户端 429/5xx/断连退避重试(惠及全部 agent);
  推理模型空正文自报 finish_reason/usage(思考吃光预算≠网络故障);
- **间隔重试梯** 0/30/60/120/300s:图像/派生关键路径骑过分钟级代理
  阵发断连;穷尽如实上抛;
- **诚实降级树**:每层失败有明确退化(agent→模板、派生→cut/continue、
  视频视图→图像编辑→master、段修无锚→自身首帧),全部留痕,
  台账绝不把降级伪装成决策;
- **全链落账**:storyboard.json(entries + junction_meta + spaces +
  backgrounds + portraits)+ brain_calls.jsonl + wavespeed_calls.jsonl
  ——任何一镜为什么长这样,可以从台账完整重放;
- **回归测试文化**:每次事故 → 根因 → 修复 + 以事故命名的回归测试
  (套件 660+,含全链冒烟);"不打补丁,从根本修复"为军规。

## 八、对照实验体系

| 档位 | 实现 | 用途 |
|---|---|---|
| 素朴基线 | `scripts/naive_baseline.py`:复用台账,纯文字 t2v 直拼(人物/背景全靠文字) | 引用体系的价值下界 |
| cinegraph | `--mode cinegraph`:严格 ViMax 移植(机位树/首帧派生/选图/多视图肖像) | 构图一致派对照;逐字移植纪律(任何一字之差单列报批) |
| window 融合派 | 本文档全部 | 现行主线 |

**已验证结论**(2026-08-09/10 对比):引用体系的价值随空间/人物"可脑补
程度"下降而上升——强先验空间(海滩/天台)素朴版也稳,弱先验空间
(面包店内)引用体系是质的差别;人物服装一致性只有肖像 refer 能保。
